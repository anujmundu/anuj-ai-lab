# Automation & Maintenance Scripts

This directory houses administrative, maintenance, ingestion batching, and data migration scripts for **Anuj AI Lab**.

---

## 🛠️ Included Utilities

- **Vector Database Maintenance**: Re-indexing and deduplication routines for ChromaDB collections.
- **Model Warm-up & Health Check**: Pre-loading preferred LLM weights into VRAM prior to query dispatch.
- **Evaluation Runner**: Batch synthetic question-answering evaluation across the knowledge base.
